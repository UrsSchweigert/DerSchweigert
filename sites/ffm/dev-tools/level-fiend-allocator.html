Level → Fiend Class Allocator

Pick which fiend class (1–36 art tier) is primarily used at each of the 60 levels. Click a row to preview it against the hero on the left. Click a row's dropdown to open the class picker — hovering an option previews it live in the canvas before you commit; click an option to actually select it. The in-game spawner still occasionally mixes in the previous 1-2 levels' classes (50% this level / 30% level−1 / 20% level−2) — that blending is unchanged, only which class each level itself points to is now yours to set. When done, click "Generate + copy" and paste the result into difficulty-classes.js, replacing the LEVEL_FIEND_CLASS_ID block.
