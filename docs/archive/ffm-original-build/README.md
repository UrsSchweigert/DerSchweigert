# Arithmo Slayer: original build prompts (archived)

These files drove the first build of Arithmo Slayer in August 2026: the product
spec (`ffm-math-game.prompt.md`), the phase prompts (`prompts/`) and the
lead/worker state file (`game-build-state.json`).

They are kept for history only. They describe a 40-level plan and an
architecture that has since changed; the current system is documented in
[`sites/ffm/README.md`](../../../sites/ffm/README.md). Do not use them as
instructions or as a source of truth.
